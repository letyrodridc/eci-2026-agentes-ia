## 📁 Estructura del Repositorio

El curso está organizado en tres clases principales. Dentro de cada carpeta encontrarás las diapositivas de la clase (PDF), así como código y ejemplos prácticos:

* 📚 **[Clase 1](./clase-1/)**: Introducción a los agentes de IA. Contiene la presentación, notebooks introductorios y primeros ejemplos de agentes.
* 🧠 **[Clase 2](./clase-2/)**: Desarrollo avanzado y casos prácticos. Incluye recursos de la segunda jornada (presentación, notebooks y código de agentes).
* 🚀 **[Clase 3](./clase-3/)**: Implementaciones complejas y cierre del curso. Contiene los materiales finales y proyectos de agentes.

Cada carpeta de clase incluye generalmente:
- `ECI 2026 - Agentes de IA - Clase X.pdf`: Diapositivas de la clase.
- `notebooks/`: Jupyter Notebooks con código y explicaciones paso a paso.
- `agentes/`: Código fuente de los agentes de Inteligencia Artificial desarrollados.
- `README.md`: Instrucciones y detalles específicos de esa clase en particular.

---

## ⚙️ Cómo utilizar este repositorio

1. **Clonar el repositorio**:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd eci-2026-agentes-ia
   ```
2. Explora el material de cada clase navegando a su respectivo directorio.
3. Te recomendamos leer el `README.md` específico dentro de la carpeta de cada clase para ver los requisitos previos y las instrucciones de instalación de las dependencias necesarias.
